## feat-001 项目依赖与脚手架扩充

- **改了什么**：
  - **Tauri 插件安装**（`pnpm tauri add`）：`plugin-sql`、`plugin-dialog`、`plugin-fs`。三者在 `src-tauri/Cargo.toml` 加为依赖、`src-tauri/src/lib.rs` 注册（`.plugin(tauri_plugin_sql::Builder::new().build())` 等）、`src-tauri/capabilities/default.json` 授权（`sql:default` / `dialog:default` / `fs:default`）。
  - **关键修复**：`tauri add sql` 自动写入的 `tauri-plugin-sql = "2"` 缺 `features = ["sqlite"]`，无 SQLite 驱动编译不过。手改为 `tauri-plugin-sql = { version = "2", features = ["sqlite"] }`。
  - **前端依赖**（`pnpm add`）：`element-plus@2.14.5`、`@iconify/vue@5.0.1`、`vditor@3.11.3`、`pinia@4.0.3`、`vue-router@5.2.0`（vue-router 4 的 latest tag 解析到 5）、`@vueuse/core@14.4.0`。**构建插件**：`unplugin-vue-components@32.1.0`、`unplugin-auto-import@21.1.0`（Element Plus 按需自动引入）。
  - **`vite.config.ts`**：加 `AutoImport({ resolvers: [ElementPlusResolver()] })` + `Components({ resolvers: [ElementPlusResolver()] })` 插件；加 `@` → `src` 路径别名（`fileURLToPath(new URL("./src", import.meta.url))`）。
  - **`tsconfig.json`**：加 `"baseUrl": "."` + `"paths": { "@/*": ["src/*"] }`；`include` 加 `auto-imports.d.ts`、`components.d.ts`（vue-tsc 能识别自动引入的类型）。
  - **`src/main.ts`**：改写为 `import App from "@/App.vue"` + `import { pinia } from "@/stores"` + `import router from "@/router"` + `createApp(App).use(pinia).use(router).mount("#app")`。
  - **新增文件**：`src/stores/index.ts`（`export const pinia = createPinia()`）、`src/router/index.ts`（占位 home 路由指向 HomeView）、`src/views/HomeView.vue`（脚手架验证页，含 `<el-button>` 证明 Element Plus 按需引入可用）。
